IPA の IT ストラテジスト試験（ST）を、令和8年度前期に受けています。システムアーキテクト（SA）と情報処理安全確保支援士（SC）はすでに合格していて、次は ST にしました。

受けると決めたのは、申込が始まった日の深夜（10/7 の 1:40 ごろ）でした。科目A（旧午前）の受験期間が 10/17 からなので、準備できるのは最短で10日ほどです。

そこで、過去問を解くためのドリルを Claude に作ってもらいました。最終的に **午前Ⅰ 300問＋午前Ⅱ 125問＝425問、全問解説付き** になり、科目A は合格しました。この記事では、その作り方と、解いて分かったことをまとめます。科目B（旧午後）は対策中なので、受験後に続編を書きます。

使ったのは Claude Code ではなく、ブラウザの claude.ai です。ドリルは claude.ai 上で動くアプリとして作ってもらいました。

## CBT 化で何が変わったか

令和8年度から、応用情報・高度試験・支援士試験が CBT 方式に変わりました。ST はその最初の回です。

| 項目 | これまで | 令和8年度から |
|---|---|---|
| 方式 | 紙 | CBT（会場ごとに予約） |
| 時期 | 春期（4月） | 前期（秋） |
| 科目名 | 午前Ⅰ／午前Ⅱ／午後Ⅰ／午後Ⅱ | 科目A-1／A-2／B-1／B-2 |

令和8年度前期の日程は次のとおりです。

- 申込：10/6〜10/24
- 科目A：10/17〜10/27
- 科目B：11/11〜11/23

前期に申し込めるのは1区分・1回だけです。ST とシステム監査（SM）はどちらも前期なので、同時には受けられません。詳しくは IPA の [令和8年度前期試験について](https://www.ipa.go.jp/shiken/2026/r08zen_exam.html) にあります。

## 午前の教材事情

午前Ⅰは、応用情報の午前から抜粋して出題されます。なので、[応用情報技術者試験ドットコム](https://www.ap-siken.com/) の「過去問道場」がそのまま使えます。

困ったのは ST 専用の午前Ⅱです。道場のようなサイトを探したところ、[ITストラテジスト過去問対策.com](https://st.ids0.com/) が見つかりました。ただ、収録は令和5年度までで、直近の令和6・7年度がありません。

足りない分は、[IPA 公式の過去問](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)（問題冊子と解答例の PDF）から作ることにしました。

## Claude と過去問ドリルを作った

### PDF を読ませるまで

すんなりとはいきませんでした。

- **問題冊子の PDF が画像だった**：テキストとして取り出せません。Claude がページを画像にして読み取り、問題文と選択肢を書き起こしました
- **Claude から IPA のサイトに届かなかった**：問題冊子の PDF は、自分でダウンロードしてチャットに添付しました
- **解答例の PDF は読めた**：正解は Claude が Web から読み取った解答例から取り、書き起こした全問と照らし合わせました

図のある問題は、原本の図を切り出して埋め込んでくれました。表は HTML で作り直しています。

### 1日で6段階に広げた

最初から 425 問を作ったわけではありません。使いながら、その日のうちに次の順で広げていきました。

1. 午前Ⅱ の令和6・7年度（50問）を、4択アプリにする
2. 全問に解説を付ける
3. 午前Ⅰ（高度共通）を足し、タブで午前Ⅰ／Ⅱを切り替える
4. 午前Ⅰを直近5年・10回分（300問）に広げる
5. 午前Ⅱを直近5年・5回分（125問）に広げる
6. 回答の記録を claude.ai のアカウントに保存し、PC とスマホで続きから解けるようにする

最後の記録の保存が、思った以上に効きました。通勤中にスマホで10問解いて、家で PC から間違えた問題を見直す、という使い方ができます。

### ドリルの機能

| 機能 | ねらい |
|---|---|
| 10問ずつ出題し、結果画面から「続きの10問」 | 80問を通しで解くのはつらいので、振り返れる単位に区切る |
| 回（年度・期）と分野で絞り込む | 分野はテクノロジ／マネジメント／ストラテジの13分野 |
| 出題範囲を「全問／未回答／直近で間違えた問題」から選び、順番は問題番号順かシャッフル | 解き残しと苦手な問題だけを回せる |
| 分野別の正答率を一覧にする | 分野名を押すと、その分野だけを出題する |
| 答案マトリクス | マークシート風の丸で直近の正誤を出し、丸を押すとその1問だけ解き直せる |
| 間違えた問題の一覧 | 自分の選んだ選択肢・正解・解説をまとめて見る |

### 解説で助かったところ

解説には、正解の理由だけでなく、**ほかの選択肢が何の説明なのか**も書いてもらいました。たとえば「イは SFA、ウは MA、エは PLM の説明」のように書いてあると、1問で4つの用語を確認できます。

もう1つは、「令和○年度 問○と同じ問題です」と再出題を明記してもらったことです。これで、次の節の傾向に気づけました。

## 解いて分かった出題傾向

一番の発見は、**午前Ⅰ・Ⅱとも再出題がかなり多い**ことです。

午前Ⅱで何度も出ていたテーマは次のとおりです。

- SECI モデル（毎年出ていました）
- 魔の川・死の谷・ダーウィンの海
- 需要の価格弾力性
- DCF 法
- マーケティング戦略の策定プロセス
- エスノグラフィー
- JIT
- プロビジョニング
- フェアユース

キャッシュフロー計算書のように、数字だけ変えて出し直される問題もあります。また、午前Ⅰと ST の午前Ⅱで同じ問題が出た回もありました（API エコノミー、CPS、バリューチェーン、CSIRT の分類）。

10日しかない中で 425 問を回せたのは、この再出題の多さのおかげでもあります。一度解説を読んだ問題が、別の回でまた出てくるからです。

## 注意点

このドリルを人に勧めるなら、次の点は伝えておく必要があります。

- **一部の回は公式の正解と照らし合わせていない**：午前Ⅰの令和4年度春期と ST 午前Ⅱの令和3年度は、解答例の PDF を Claude が読み取れませんでした。この2回の正解は、Claude が問題を解いて決めたものです
- **分野分けと解説は非公式**：どちらも Claude が作ったもので、IPA のものではありません
- **過去問の利用条件**：IPA は過去問の利用に許諾を不要としていますが、留意点があります。使う前に [IPA の過去問のページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) を確認してください

ドリル自体は自分の勉強用で、公開はしていません。

## 結果と、午後に向けて

科目A は合格しました。今は科目B（11/11〜）の対策をしています。

科目B では、CBT ならではの注意点があります。問題文はコピーできず、論述欄には字数の上限があり、上限を超えた分は削除されます。カット・コピー・ペーストも画面のボタンでしかできません。公式の操作説明と体験版は [CBT-Solutions のページ](https://cbt-s.com/examinee/examination/ap_koudo_sc_r8cbt_zenki) にあります。

午後Ⅰ（科目B-1）は、時間を計って自分で解いた答えを Claude に送り、IPA の解答例と採点講評に照らして採点してもらっています。Claude には、自分が解き終わるまで答えを見ずに待ってもらっています。

論文（科目B-2）は、本業のゲーム開発での経験を「IT ストラテジストとして事業戦略から IT 施策を立案した」立場に組み直すところから始めました。このあたりは、受験後の振り返りでまとめて書きます。
